Conectar con GitHub

¿Cómo consigo la clave? (se hace una sola vez)
  1. Entrá a github.com/settings/personal-access-tokens/new con tu usuario vcarrizo.
  2. Nombre: Promos web WL. Vencimiento: el que prefieras (por ejemplo, 1 año).
  3. En Repository access elegí Only select repositories → wldistribuciones.
  4. En Permissions → Repository permissions, poné Contents en Read and write. Nada más.
  5. Tocá Generate token, copiala y pegala acá.

Esa clave solo puede modificar los archivos de la web. No la compartas; si se filtra, la borrás desde la misma página de GitHub y generás otra.
